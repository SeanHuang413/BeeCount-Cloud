# 分类图片预设

在分类图标选择器的“扩展图标”中直接选择。预设不创建、重命名或自动改变分类。
选择时自动准备 PNG 并调用现有 user-global 分类图片上传接口；点击分类保存后，
现有写入 API 会将文件 ID 与 SHA 写入分类并产生同步事件。
手机通过原有自定义图片机制下载，实际客户端显示需在设备上验证。

130 个预设包含用户提供的 78 个父子分类位置、41 个新增常用主题及 30 个商家图标。
商家图标覆盖 12 个电商、14 个超市及 4 个便利店；使用统一购物图形加商家简称徽记，
属于自制识别图标，不是官方品牌 logo。商家预设支持分类旧名称、英文名称及用途关键词搜索。
已增加独立商家预设的名称优先由专属预设承接，不再作为通用超市/电商图标的别名。
天然气等同义用途仍可复用图片。
收入/支出和父子关系不由图标名称推断，正式分类数据尚未应用。

8 张 PNG 来自内置 imagegen，画风为蓝灰双色、圆角、透明背景、无文字，
提示词为各分类主体加统一颜色 #496A88 / #C7DAE8 和透明背景、居中留白约束。
原始生成文件保留在 output/category-icons/blue-gray-v1 和生成图片目录。
其余 122 个 SVG 从项目已有 lucide-react 0.462.0（ISC 许可证）图形制作，
采用相同颜色、512×512 画布及统一圆角笔画。矢量源可继续调整。
图库统一按收支配色，不再提供原始蓝灰切换，从 --income-rgb / --expense-rgb 读取当前主题颜色；
同一个图形可按当前分类类型保存为收入色或支出色，不根据图标名称更改分类类型。
主题 RGB 必须通过校验，缺失时使用蓝灰原色，转账同样使用蓝灰原色。
全部图标都保留 SVG 配色源；八张生成 PNG 的源文件保留为设计资料，
选择器使用相同主题的矢量配色图形。预览与导出的 PNG 使用同一配色源。
配色后在浏览器导出 512×512 透明 PNG；不会向移动端传 SVG 或新增图标类型。
图片颜色是保存时的快照，之后更换主题不会改写历史图片，需重新选择并保存。
PNG 原图保留高分辨率；显示时使用 contain，分类卡片沿用 42/34px、详情 40px。

图库来源在 catalog.ts 中显式声明，经 Vite 打包为静态资源，不依赖 output 目录。
每次新增资源时同步 catalog.ts；禁止将未生成资源占位为已完成图标。
