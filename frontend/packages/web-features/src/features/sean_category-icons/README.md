# 分类图片预设

在分类图标选择器的“扩展图标”中选择。选择时在浏览器导出 512×512
透明 PNG，调用现有分类图片上传接口；保存分类后通过现有机制同步。
不改变分类名称、类型、父子关系或同步协议；已有分类需要重新选择并保存才更新图片。

## 当前图库：pastel-vector-v2

共 138 项，包括 108 个生活及收入主题和 30 个商家主题（12 个电商、14 个超市、
4 个便利店）。ID、名称、搜索关键词和分组保持不变。商家使用购物袋、店铺及简称，
属于自制识别插画，不是官方品牌 logo。

依据用户认可的彩色预览重新绘制 SVG：浅蓝、薄荷绿、暖黄、蜜桃、淡紫、珊瑚色，
统一圆角描边及透明背景。每个主题具有独立构图，相关用途复用同一图形语言。
`assets/pastel-vector-v2/` 是当前静态资源，`catalog.ts` 显式声明全部来源。
预览和导出使用同一 SVG；`colorMode: "multicolor"` 保留主体原色。收入添加＋角标，支出添加－角标，角标颜色读取系统收支主题；转账不添加标记。标记一起写入 PNG，切换主题不会改写已保存图片。
手机接收的是 PNG，不需要新的图标名注册或 SVG 字体支持，实际设备显示仍需验证。

## 编辑、导出与检查

- `scripts/design_category_icons.py`：原生矢量绘制源，Python 标准库即可生成全套 SVG、清单和 HTML 总览；清单缺项时失败。
- `scripts/qa/render_category_icons.cjs`：可选设计检查工具，使用 sharp 导出全套透明 PNG，并检查尺寸、透明通道及角点；生成含 42px、32px 实际尺寸的总览。
- `output/category-icons/pastel-vector-v2/index.html`：完整预览，可随系统切换明暗背景。
- `output/category-icons/pastel-vector-v2/overview.png`：整套静态总览。
- `output/category-icons/pastel-vector-v2/png/`：512px PNG 导出文件。

运行生成器后再运行导出工具；后者需要可解析的 sharp 模块（桌面工作区运行时已提供，
可通过 NODE_PATH 指定），它不是生产依赖。Web 生产构建只引用 assets，不依赖 output。

旧版蓝灰图形与上一轮生成的 PNG 作为设计资料保留，当前选择器不引用它们。

新增飞哥结婚、喜酒、平账、居家生活、鞋子、衣服、包包和其他报销预设；拼多多沿用专属预设，增加精品购物搜索词。父级名称仅用于搜索，不自动写入分类层级或收支类型。
运行导出工具时可加 `--additions`，生成这批项目的 `additions.png` 九宫格预览。
