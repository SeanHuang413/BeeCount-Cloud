# 精品购物统一图标

小象超市、叮咚购物、沙井老店已接入正式扩展图库；打包和独立上传共用同一组 SVG 与角标、配色渲染器。

每项提供 512×512 透明 PNG：`-income.png` 为收入＋，`-expense.png` 为支出－，颜色读取样式表默认主题并保存为快照。应用内选择则使用当前用户主题。无角标版本作为原图保留。

运行 `node scripts/qa/export_category_icon_uploads.cjs` 可单独重建；完整设计导出工具也会自动生成本目录。需要 sharp 和前端已安装的 TypeScript。`manifest.json` 记录正式来源和对应版本。保存分类后沿用原有同步机制；仅更新图库不自动覆盖用户已有图片。商家图形为自制识别插画。
